# Dashboard screenshots

These images are generated by `scripts/capture_screenshots.py` from the local Streamlit
app at a 1440×900 viewport. The capture waits for and verifies the synthetic Demo Plant
before saving the Overview, Charts, Segments, and Economy tabs, so no proprietary
Enerjisa data appears in the screenshots.

After installing `requirements-streamlit.txt` and the `screenshots` optional dependency,
install Chromium once and capture all four images:

```bash
python -m playwright install chromium
python scripts/capture_screenshots.py
```
